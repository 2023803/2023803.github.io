# 部署说明

此压缩包是 `2023803/2023803.github.io` 的定制主页文件。

## GitHub 网页操作

1. 在仓库中删除旧的 `index.html` 和 `index.md`，避免它们与 `_pages/about.md` 的主页地址冲突。
2. 解压本文件，将解压目录中的所有文件和文件夹上传到仓库根目录。
3. 如果 GitHub 提示同名文件，选择用新文件覆盖 `_config.yml` 和 `README.md`。
4. 将变更提交到 `main` 分支。
5. 打开仓库的 **Actions** 页面，等待 `pages build and deployment` 显示绿色对勾。
6. 访问 <https://2023803.github.io>。

头像已嵌入 `_includes/avatar.html`，不需要另外上传图片文件。
